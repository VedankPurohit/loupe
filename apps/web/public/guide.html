Loupe / local setup guidance

From a trusted hook to a useful Session.

Loupe is a local-first observability surface for supported Codex capture. This page names the safe starting path without implying unsupported fidelity or production hosting.

The path

  1. Start the local PostgreSQL, Fastify, and Vite services from the repository root.
  2. Open the homepage and authenticate with the configured Google Web client.
  3. Create an Organization, redeem an Administrator invite, or select an existing membership.
  4. Use Device diagnostics to verify hook trust, relay health, and delivery acknowledgement.
  5. Inspect captured Sessions only after the evidence path is available. Unsupported fields remain explicitly unavailable.

What Loupe does not do yet

This local milestone does not promise production domains, managed hosting, or complete provider Context/cost fidelity. Seeded Example data is synthetic and stays labelled as such.
