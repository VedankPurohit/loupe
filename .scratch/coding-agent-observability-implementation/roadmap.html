01 / The mechanism

A signal route from laptop evidence to Organization learning.

The product is not a generic token dashboard. Its unusual mechanism is the preserved chain of evidence: source truth survives every projection, recommendation, approval, and rollout.

Fixtures help tests and onboarding; they never replace capture, persistence, search, comparison, or CLI evidence.

Truth has a label

Documented, observed, inferred, unstable, and unavailable stay distinct through every surface.

Humans approve

An agent can propose a complete skill. Only an Administrator can approve the exact immutable artifact.

Devices obey safely

04 / How the work runs

One orchestrator. A tested frontier. Documentation in the loop.

The ticket loop

1Pick a ticket whose blockers are complete.
2Use its required skills and split internal work across subagents where useful.
3Write the first failing behavior test at the confirmed seam.
4Implement one vertical tracer bullet until the ticket's acceptance criteria pass.
5Update the relevant contracts and documentation before marking the ticket complete.

What every ticket carries

  • Type and required skills so the agent knows whether it is implementing, prototyping, verifying, or documenting.
  • A highest-seam testing plan naming the first red behavior, real-versus-fixture boundary, and verification path.
  • A documentation obligation tied to the behavior introduced—not postponed until the end.
  • Explicit blockers so the orchestrator can work the dependency frontier rather than following file order blindly.
  • Downgrade behavior wherever Codex evidence may be weaker than hoped. Unsupported data becomes unavailable, not invented.

05 / Evidence boundary

Five labels prevent one convincing lie.

Evidence stateWhat it meansHow the product behaves
DocumentedNamed by the supported public Codex surface.Use directly, still retain producer version and provenance.
ObservedFound in first-party source or artifacts, but not promised publicly.Show with version context; tolerate change.
InferredCalculated or correlated from retained evidence.Show method, inputs, confidence, and missing assumptions.
UnstableExperimental, internal, transcript, rollout, or version-gated.Keep isolated and downgrade safely when the producer changes.
UnavailableThe source cannot support the requested fact.Never turn it into zero, false, or a plausible guess.

06 / Scope line

Build the learning loop. Refuse the platform sprawl.

Real in this MVP

CaptureCodex on macOS, user-level OTel and hooks, restartable relay, durable local delivery.
OrganizationOne self-hosted Organization, real Members, Organization-visible Sessions, scoped credentials.
InvestigationTimeline, Agent hierarchy, provenance, search, comparison, Token/Context evidence, citations.
LearningAnalysis CLI and skill, complete Candidate skill, Administrator approval, mandatory synchronization.
OperationDocker-free native development, one-command Compose deployment, repository-native documentation.

Explicitly not now

  • Remote control or steering
  • Agents beyond Codex
  • Linux and Windows daemons
  • Multi-Organization hosting
  • Automatic approval
  • Member opt-out from standards
  • Productivity leaderboards
  • Background pattern mining
  • Semantic vector search
  • Full CI/PR/deployment outcomes
  • Historical backfill
  • Kafka or Kubernetes
